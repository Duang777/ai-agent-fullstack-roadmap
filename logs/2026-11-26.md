## 今日学习
- 知识点：4.5 TS 生态：Vercel AI SDK、Mastra 与 OpenAI Agents SDK (JS)
  - 用真库：`ai` 7.0.183、`@mastra/core` 1.86.0、`@openai/agents` 0.22.0，三家共用一个客服场景（查订单、退款、超过 500 要审批）
  - AI SDK 7 改了很多名字：`isStepCount`、`instructions`、`onEnd`、`stream`、`toolApproval`、`runtimeContext` / `toolsContext`；结果上的 `usage`、`toolCalls` 改成累计所有步骤
  - `ToolLoopAgent` 默认 `isStepCount(20)`，`generateText` 默认 1 步：工具会执行，但不再调模型，回答为空
  - 撞到上限：AI SDK 和 Mastra 正常返回（`stoppedBy` / `finishReason` 才能看出来），OpenAI 抛 `MaxTurnsExceededError`
  - 工具错误：AI SDK 和 Mastra 把抛错、工具不存在、参数错误都交给模型；OpenAI 默认只给一句通用文案，工具不存在默认抛错
  - 审批：AI SDK 两次调用、状态是消息历史；Mastra 是 storage 快照，另一个实例拿 runId 就能批准；OpenAI 是 `RunState` 字符串
  - Mastra 直接用 AI SDK 的模型对象；默认 `maxSteps` 只有 5；workflow 恢复时挂起的步骤重跑、已完成的不跑
