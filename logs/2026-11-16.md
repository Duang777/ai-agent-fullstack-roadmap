- 知识点：4.4 Go 生态：Eino、Genkit Go 与官方 MCP Go SDK
  - 这一课不重写运行时，直接用真库：Eino v0.9.23、Genkit Go v1.14.0、MCP Go SDK v1.8.0
  - Eino compose：`NewGraph[I, O]` 的类型在连边时检查，第一个错误粘在图上；状态用 `WithGenLocalState` + pre/post handler 显式读写；整图 Invoke 时内部全是 Invoke，要流式就整图 Stream

  - ADK：`MaxIterations` 数模型调用（默认 20）；同一轮工具默认并行；调用不存在的工具默认整次运行失败，`UnknownToolsHandler` 兜底；`ChatModelAgent` 用调用选项传工具，不调 `WithTools`
  - Eino 中断：`StatefulInterrupt` / `GetInterruptState` / `GetResumeContext`；不是恢复目标就原样再中断；状态类型要注册 gob；跨实例恢复只需要共享 `CheckPointStore`
  - Genkit：`maxTurns` 数工具轮（默认 50），设成 2 时模型被调 3 次；`tool.Fail` 交还模型，普通错误中止；参数不符合 schema 时整个 Generate 失败；可恢复工具 `Restart` / `Respond`，状态在 `History()` 里由你保存
  - MCP Go SDK：先 `server/discover` 协商 2026-07-28，失败回退 initialize；`AddTool` 先校验参数再调 handler；handler 的 error 是工具错误（`IsError`），工具不存在才是协议错误；MRTR 默认由客户端的 `ElicitationHandler` 自动应答
  - Genkit 的 `plugins/mcp` 和 eino-ext 的 `tool/mcp` 用的是 mark3labs/mcp-go，要新协议特性就自己用官方 SDK 写适配器
