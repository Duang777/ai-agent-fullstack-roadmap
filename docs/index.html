  1. Day 12 · 2026-10-20

    三种 Agent 模式：每一步想、先全想好、做完再想

    • ReAct 的工具报错直接 return，模型就失去了自己改正的机会
    • 文本格式的 ReAct：模型会顺手编一段 Observation，必须截断
    • ReWOO 用 #E1 引用串起计划，依赖一推就能分波并行
    • 模型写的计划先校验：重复 ID、悬空引用、循环、未知工具
    • Reflexion 的效果取决于评估信号，没有测试就别指望它

    思考：你的任务里，哪些步骤其实可以事先写死？

  2. Day 11 · 2026-10-18

    代码执行沙箱：默认代码是不可信的

    • 超时只杀了 sh：后台的 sleep 30 还活着，要杀整个进程组
    • exec 默认继承全部环境变量：代码里一句 env 就看到你的 API Key
    • 不加 set -e：写文件被 SIGXFSZ 杀掉，脚本退出码仍是 0
    • 产物目录里放一个指向 /etc/passwd 的符号链接：收产物要用 Lstat
    • io.Writer 返回值写错，子进程的输出被直接丢掉

    思考：你的 Agent 跑的代码，能读到你服务器上的哪些东西？

  4. Day 9 · 2026-10-16

    A2A 1.0：Agent 之间委托任务

    • 远程 Agent 不是函数：会跑很久、会反问、会要授权，结果分块产出
    • 任务执行用请求的 context：returnImmediately 一返回，任务就被杀掉
    • 取消时先 cancel 再写状态：Executor 抢先返回，CANCELED 变成 FAILED
    • 同一个 messageId 重发“扣款 100 元”：只执行一次
    • 远程 Agent 反问“从哪里出发”：不是错误，把问题和 task_id 交给模型

  5. Day 8 · 2026-10-15

    Function Calling：模型不执行工具，你的代码执行

    • OpenAI 的 arguments 是 JSON 字符串，Anthropic 的 input 是对象：一个结构体解析两家会出错
    • 并行调用的结果拆成多条 user 消息：不报错，但会让模型不再并行
    • 4 个 50ms 的只读调用：并发 51ms，串行约 200ms
    • create_branch → write_file 失败 → commit 不执行，返回“未执行”
    • 拼错的工具名、缺参数、超时、panic：全部变成错误结果回给模型

    MCP（2026-07-28）：没有握手，没有会话

    • 每个请求在 _meta 里自带版本和能力；任何一台机器都能处理任何一个请求
    • Server 要用户确认：返回 input_required，客户端带着回答用新 id 重发
    • requestState 不绑定参数：一次无害的确认就能删掉另一个仓库
    • 网关按头放行 get_weather、Server 按 body 执行 delete_repo：头和 body 必须一致

    思考：你的 Agent 里哪些工具是有副作用的？你接的第三方 MCP Server，它的工具描述你读过吗？

  7. Day 6 · 2026-10-13

    推理模型：effort、thinking 与成本；Prompt Caching

    • 可见输出一模一样，多了 8000 推理 token，成本是 21 倍
    • Gemini 的 total_output_tokens 不含思考：照字段算，成本只算到 38%
    • 用 HMAC 模拟思考块签名：改摘要一个标点就 400；改一个工具结果，之后的思考全部失效
    • 逐级升级 low→medium→high：98.3% 正确、4064 token/题；永远 high 是 92.6%、12300 token/题
    • 验证器放过一半错答，成功率从 94.4% 掉到 56.6%，账面上还更省钱
    • 1.5：30 轮 Agent 会话，断点跟着最后一块走，输入成本只剩 16.6%，命中率 94.3%
    • 同样的会话，system 开头写一行当前时间：命中率 0%，成本 125%，比不缓存还贵
    • 用户每 3 到 40 分钟回一次：5 分钟 TTL 只省 6%，1 小时 TTL 省 73%

  8. Day 5 · 2026-10-12

    Transformer、Tokenizer 与采样；主流模型 API；结构化输出

    • 1.3：手写约束解码器，100 次随机抽样全部通过校验；但模型想说 unsure 时，enum 只给 yes/no，它只能编一个
